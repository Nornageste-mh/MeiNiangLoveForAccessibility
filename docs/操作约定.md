# 操作约定（男娘恋爱物语 · 无障碍补丁 0.1.1.0）

本文件说明：打了补丁之后，**键盘操作和原版有什么相同、什么不同**，以及每一处新增热键的
冲突核查记录。原件在 `Framework/docs/操作逻辑公约.md`，本文件只写本作的落地与差异。

## 一、总则

1. 不覆盖游戏原生键：方向键 / 回车 / 空格 / Esc / 鼠标的所有行为保持原样。
2. 不设模式开关：没有任何"进入无障碍模式"的按键；界面一出现，键盘直接可用。
3. 语义与公约一致：↑↓ 浏览、←→ 调值、Enter/Space 激活、Esc 返回、Backspace 重读、
   0 沉默/重读（本作沿用引擎语义）、1–9 选项、Alt+Shift+F9 换语音后端。
4. 玩家按游戏自带的 `V` 关掉自语音时，补丁完全闭嘴（可摘除的另一层保险）。

## 二、键位表

| 键 | 原版行为 | 打补丁后 | 差异登记 |
|---|---|---|---|
| ↑ / ↓ / ← / → | 方向键导航 / 调值 | **不变**。开自语音时引擎自己把方向键改成顺序导航（`focus_ordered`），这是引擎的无障碍行为，补丁没有改键位表 | 无（引擎行为） |
| Enter / Space | 推进台词 / 激活按钮 | 不变 | 无 |
| Esc | 游戏菜单 / 返回上一级 | 不变 | 无 |
| 鼠标 | 点击 | 不变 | 无 |
| `V` | 引擎自语音开关（游戏把 alt+V 从 keymap 去掉了，但 V 仍在 `self_voicing` 里） | 不变；关掉后补丁也闭嘴 | 无 |
| `Shift+A` | 引擎无障碍菜单 | 不变 | 无 |
| **Backspace** | 原版无功能 | 重读最近一句；选项界面里把整组选项连编号念一遍；输入框内让位（仍是删除） | 新增（朗读侧，公约允许） |
| **Alt+Shift+F9** | 原版无功能 | 切换语音后端（NVDA → 争渡读屏 → SAPI → 日志，自动跳过不可用档位），并念出切换结果 | 新增（朗读侧，公约允许） |
| **1–9**（主键盘与数字小键盘） | 原版无功能 | 剧情选项界面直接选择第 N 项（调用该选项自己的 action，与点击同一条路）；其它界面完全不响应 | 新增（选项补键，见第四节） |

## 三、冲突四项核查（Framework 交互形态纪律 §3 B）

| 检查项 | 结论 | 依据 |
|---|---|---|
| 游戏自身键位表 | Backspace / Alt+Shift+F9 / 1–9 均未绑定（`gui.rpy:40-47` 只改了 rollback、hide_windows、game_menu、dismiss、self_voicing）；输入框内 Backspace 由 `renpy.display.behavior.Input` 自己处理，补丁检测到焦点是 Input 就直接放行 | [文件] 反编译 `gui.rpy`，[实测] 输入框用例 |
| 平台键（Steam F12 截图等） | 不使用 F1–F12 单键；Alt+Shift+F9 不与 Steam 截图/录像默认键冲突 | [文件] Steam 默认键位 |
| 读屏器组合键（NVDA / 争渡） | NVDA 主要用 NVDA 键（Insert/CapsLock+…）、争渡用其自己的热键层；Backspace 单键、1–9 单键、Alt+Shift+F9 均不在两者默认手势中 | [推断] 默认手势表；真机待手测确认 |
| 输入法/系统占用 | 中文输入法激活时数字键可能用于选字；补丁只在剧情选项界面响应，玩家可用 Shift 切英文输入后再按数字键（README / FAQ 已写） | [推断] 待手测；不影响方向键+回车的老路 |

处理顺序按公约"改键 > 加修饰 > 减功能"：本作无需改键，只加了 1 个单键（Backspace，
原本空着）、1 个组合键（Alt+Shift+F9，避开功能键区）、9 个数字键（仅在选项界面生效）。

## 四、1–9 选项键的性质与限制（差异登记）

- 为什么加：选项文字是图片按钮，靠方向键逐项听虽然可行，但盲人要"听—记—再找"来回按；
  数字键把"第几项"变成一次按键，这正是 `操作逻辑公约.md` 语义动作表里的标准动作。
- 怎么加：`renpy.Keymap`（与引擎自己绑定 V / Shift+A 的方式完全相同），事件名独立
  （`mne_choice_1..9`），不改任何引擎键；处理函数只在 `renpy.get_screen("choice")` 存在时
  生效，取的是游戏 choice 界面的 `items`（caption + action），调用的是玩家点击时同样的
  action，不伪造输入、不抢焦点。
- 编号从哪来：焦点落在选项上时，补丁在朗读文字前加"1、""2、"……（念出来的编号与实际
  按键一致）；也可以按 Backspace 一次听完整组"选项：1、…；2、…"。
- 如果玩家不喜欢：删掉 `07_choice.rpy` 即可（不影响其它朗读）。

## 五、和原版行为的一致性

- 不打补丁 / 删掉 `game/a11y_platform`：游戏与原版一致（自动化用例每次跑完都做逐文件
  SHA256 校验，见 `evidence/`）。
- 打补丁但按 `V` 关自语音：补丁不再出声，按键除 Backspace/F9/数字键外与原版一致。
- 补丁不新增任何可见元素：不改屏幕、不加覆盖层、不改字体/颜色/布局。
