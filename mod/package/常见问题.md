# 常见问题

## 完全没声音

1. 先确认读屏状态：NVDA 已启动？争渡（商业版/青春版）已启动？两者都没有时补丁会回落 SAPI。
2. 打开 `<游戏目录>\a11y_speech.log` 看最后几行：
   - `补丁 0.1.1.0 已加载` 有没有？没有说明没装上（检查 `game\a11y_platform\*.rpy` 是否存在）。
   - 后端选择那行：`NVDA=True` / `争渡=True` / `选用=引擎SAPI` / `选用=日志`。
     如果显示 `选用=日志`，说明三种语音都不可用（日志档只是不出声，方便排查）。
3. 按 `Alt+Shift+F9` 切换语音后端，听是否念出"朗读已切换到 ..."。
4. 如果按了 `Alt+Shift+F9` 只是切了输入法：中文 Windows 的输入法切换就是 `Alt+Shift`，
   请先切到英文输入状态再按。

## 只有第一句能念，后面不念了

- 先按 `V` 看一下自语音状态（引擎自己会念"朗读已开启 / 已关闭"的中文版）。
- 游戏把 `Alt+V` 的自语音键清掉了，但单按 `V` 仍然可以开关，补丁默认帮你打开过一次。
- 如果是 1.0 之外的版本，界面结构可能不同，请联系测试负责人。

## 有配音的台词不朗读

这是**设计行为**：有配音的句子只播放游戏语音，不念任何文字，避免语音和读屏叠在一起。
想听文字按 `Backspace`，会把整句连同说话人念一遍。

## 按数字键没反应 / 选错选项

- 数字键只在**剧情选项界面**生效；其他界面数字键会放行给游戏。
- 如果同时开着输入法，请切到英文输入状态再试（数字键可能被输入法吃掉）。
- 选项出现时应能先听到"选项：1、…；2、…"（整组重念用 `Backspace`）。

## Backspace 在输入框里不能删字

不应该发生：补丁在输入框里会把 Backspace 让给游戏。如果确实发生，请记录界面位置与复现步骤。

## 菜单按钮念的是"开始游戏：读取游戏：设置…"一整串

这是引擎负责的整屏朗读（界面出现时念一次），不是补丁加的模式。
之后用方向键逐项浏览时是逐项朗读的。

## 有配音台词前会先念一句"2023年"

这是引擎对 say 界面整屏根的朗读（日期装饰），补丁已经修正台词本体，但这一条
整屏朗读不在补丁接管范围内。属已知现象。

## 装了补丁后画面有任何变化吗

不应该有。补丁不新增任何可见元素、不改颜色/布局；如果发现画面差异，请立即报告并附截图。

## 想彻底确认补丁装了什么

运行 `pwsh -File .\tools\verify.ps1` 可逐文件校验（与发布包 SHA256 对比），
再对照 `tools\` 生成的安装清单。
