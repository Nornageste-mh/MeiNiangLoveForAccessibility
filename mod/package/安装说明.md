# 安装说明（发给测试同学）

版本 0.1.1.0。补丁是 Ren'Py 覆盖层，**不修改任何游戏文件**，安装就是往游戏的
`game\` 里放一个目录。

## 一、准备工作

- Windows 10 / 11，已通过 Steam 安装《男娘恋爱物语》。
- 语音后端（按推荐顺序，有一个能出声就行）：
  1. **NVDA**（推荐，<https://www.nvaccess.org/>）—— 补丁自带控制器客户端 dll，NVDA 开着即可；
  2. **争渡读屏**（ZDSR，商业版 / 青春版）—— 补丁会自动找它的安装目录，不随包带 dll；
  3. **Windows SAPI**（系统自带）—— 没装读屏时自动回落，需要系统里有中文语音。

## 二、一键安装（推荐）

1. 把整个 `MeiNiangLoveForAccessibility` 文件夹解压到任意位置（例如桌面）。
2. 右键开始菜单 → "Windows PowerShell"，进入解压后的目录：

   ```powershell
   cd "C:\Users\你的用户名\Desktop\MeiNiangLoveForAccessibility"
   pwsh -ExecutionPolicy Bypass -File .\tools\install.ps1
   ```

3. 脚本会打印找到的游戏目录、复制了哪些文件，最后提示"安装完成"。
   如果提示"没找到游戏目录"，请手动指定：

   ```powershell
   pwsh -File .\tools\install.ps1 -GameDir "D:\Steam\steamapps\common\mei"
   ```

4. 启动游戏。首次启动会在游戏目录生成 `a11y_speech.log`（自检日志），可用来排查问题。

## 三、手动安装（脚本无效时）

1. 复制 `mod\game\a11y_platform` 整个文件夹到：

   ```
   <游戏目录>\game\a11y_platform
   ```

2. 复制 `mod\nvdaControllerClient64.dll` 到：

   ```
   <游戏目录>\nvdaControllerClient64.dll
   ```

3. 如果 `<游戏目录>\game\a11y_platform` 里出现 `*.rpyc` 旧文件，全部删掉（否则游戏会优先
   使用旧的编译缓存，表现为"改了什么都没变"）。

## 四、确认装好了

启动游戏后应该能听到标题菜单按钮（开始游戏 / 读取游戏 / 设置 / 关于 / 相册 / 退出）。
也可以看日志文件 `<游戏目录>\a11y_speech.log`，里面应有：

- `补丁 0.1.1.0 已加载`
- `NVDA=...` / `争渡=...` / `选用=...`（后端选择结果；测试机上没有读屏时会写 `选用=日志`）
- `已绑定 Backspace=重读 / Alt+Shift+F9=切换后端`
- `已绑定数字键 1–9=直接选择剧情选项（仅选项界面生效）`

## 五、切换语音后端

运行中按 `Alt+Shift+F9`，会在 NVDA → 争渡 → SAPI → 日志 之间切到下一个**当前可用**的档位，
并由读屏报出"朗读已切换到 …"。

- 先开游戏、后开读屏也没关系：补丁每 5 秒重探一次，会自动接上（只升不降）。
- 想固定用某一档，可设环境变量 `A11Y_TTS_PREF=nvda` / `zdsr` / `sapi` / `log`。
- 争渡装在非默认目录也能被找到（读「卸载」登记项 + 常见路径）；
  实在找不到时可设 `A11Y_ZDSR_DIR=<争渡目录>`。

## 六、卸载

```powershell
pwsh -File .\tools\uninstall.ps1
```

或手动删除：

- `<游戏目录>\game\a11y_platform\`（整个目录）
- `<游戏目录>\nvdaControllerClient64.dll`
- 如果还有 `<游戏目录>\game\a11y_platform\*.rpyc` 一并删除

存档不受影响（Ren'Py 存档在 `%APPDATA%\RenPy\mei-1745999714\`）。

## 七、安装脚本做了什么（可审计）

- 只在游戏目录里**新增**文件，不修改任何游戏原始文件（脚本显式拒绝写
  `D:\Steam\steamapps\common\` 之外的路径时只在用户指定 `-GameDir` 时生效）。
- 记录 `.install-manifest.json`（每个文件的 SHA256），方便校验与卸载。
- `-Verify` 参数可逐文件校验是否与发布包一致（`tools\verify.ps1` 同理）。
- 不碰存档、不改 `game\*.rpa`、不改 `renpy\` 与 `lib\`。
