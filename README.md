## 说明

本辅助的作用：让使用读屏软件的玩家，也能基本正常地游玩《男娘恋爱物语》。

- 朗读**没有配音**的剧情文本（旁白、无配音台词），台词只取台词本体，
  不会把界面上的日期装饰（本作每句前的"2023年"）一起念出来
- 有配音的台词只放游戏语音、**不叠读**（**想听文字按 `Backspace`**，
  会把这一句连同说话人念一遍）
- 朗读界面：标题菜单、设置、存读档、快捷栏、确认框 —— 由游戏自己的
  焦点事件驱动；对游戏把文字画在图片上的按钮，补丁在引擎朗读出口后补念文字
- 朗读剧情选项（带 1、2、3 编号），并可用数字键 `1`-`9` 直接选择
  （调用的就是鼠标点击会走的那条游戏逻辑，不是模拟按键）
- 键盘导航用的是**游戏自己的**：方向键浏览、回车/空格激活、`Esc` 返回，
  补丁不新增导航模式、不抢方向键
- **语音后端按可用性自动挑**：NVDA → 争渡读屏（ZDSR）→ SAPI（引擎自带）；
  运行中可用 `Alt+Shift+F9` 切到下一个当前可用的后端，并由读屏报出结果
- **默认开启**：首次启动把引擎自己的"自语音"打开（等价于玩家按一次 `V`，
  存进游戏的 persistent）；之后玩家按 `V` 关掉就**不再自动打开**

游戏版本：Ren'Py 8.5.2（本补丁针对 Steam 正式版 1.0 制作，Ren'Py 补丁是纯
`.rpy` 覆盖层，游戏小版本更新通常不受影响）。

## 安装（仅限正版玩家）

**最快的装法**：到 [Releases](../../releases) 下载整合包 zip，解压后运行
`tools\install.ps1`（会自动找 Steam 库里的游戏目录，也接受 `-GameDir` 手动指定）。

Ren'Py 补丁**不修改任何游戏文件**，安装就是「往 `game\` 里放一个目录」：

- 把 `mod\game\a11y_platform\` 整个目录复制到 `<游戏目录>\game\a11y_platform\`
- 把 `mod\nvdaControllerClient64.dll` 复制到游戏根目录（有 `mei.exe` 的那一层）
- 如果 `game\a11y_platform\` 里出现 `*.rpyc`，**全部删掉** —— Ren'Py 会优先用编译缓存，
  留着旧 `.rpyc` 的表现是"改了什么都没变"

三条容易踩的坑：

- `game\a11y_platform\` 必须直接位于 `game\` 下（多套一层目录不会加载）
- `nvdaControllerClient64.dll` 必须在**游戏根目录**（与 `mei.exe` 同级）
- 不要动游戏自带的 `game\*.rpa`、`renpy\`、`lib\` —— 补丁不需要，也不要改

卸载：删掉 `<游戏目录>\game\a11y_platform\` 整个目录和
`<游戏目录>\nvdaControllerClient64.dll` 即可完全恢复原版行为；
也可以用 `pwsh -File tools\uninstall.ps1`。
存档在 `%APPDATA%\RenPy\mei-1745999714\`，不受影响。

详细步骤、按键表、故障排查见 [`mod/package/安装说明.md`](mod/package/安装说明.md)。

> 再次提醒：请通过 Steam 购买正版《男娘恋爱物语》后再使用本辅助。

## 主要快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Backspace` | 重读最近一句（有配音的台词也能重读）；选项界面重念整组选项；输入框内让位给游戏 |
| `1` - `9` | 选择对应编号的选项（只在剧情选项界面生效，其余时候放行游戏原键） |
| `Alt+Shift+F9` | **切换语音后端**（NVDA → 争渡 → SAPI → 日志，自动跳过不可用的档位） |
| `↑` `↓` `←` `→` | 游戏自己的界面焦点导航（补丁只朗读，不接管） |
| `回车` / `空格` | 游戏自己的"确认/推进"（补丁不拦截、不静音） |
| `Esc` | 游戏自己的"返回/菜单" |
| `V` | 游戏自己的"自语音开/关"（补丁默认帮你打开一次，之后听你的） |

**游戏原生占用的键**（模组不会去抢）：
`回车`/`空格`/小键盘回车 推进、`Esc` 菜单、`Ctrl` 快进、`PageUp` 回滚、
`H` / 鼠标右键 隐藏窗口、`Shift+A` 引擎无障碍菜单、`V` 自语音、
`s` 截图、`f` 全屏。本作还在 `gui.rpy` 里清空了 `Alt+V` 与 `PageUp` 的
原生绑定，所以补丁只加了自己的事件名（`mne_repeat_line`、`mne_cycle_backend`），
**一个游戏原生键都没有覆盖**。

> `Alt+Shift+F9` 里的 `Alt+Shift` 是中文 Windows 的输入法/输入语言切换键。
> 如果按下后只是切了输入法、没有切换后端，请先把输入法切到英文状态再按；
> 补丁的绑定要求修饰键完全匹配，单按 `F9` 不会触发。

> **争渡读屏（ZDSR）这一档不需要你做任何事**：模组会**自动找**争渡的安装目录 ——
> 先读 Windows「卸载」登记项里的 `InstallLocation`（`DisplayName` 含「争渡」或
> `zdsr`；HKLM 两个视图 + HKCU 都枚举），找不到再试
> `%ProgramFiles(x86)%\zdsr\zdsr` 这类默认位置。所以**装在别的盘、装到自定义目录也算数**。
> 也可以用环境变量 `A11Y_ZDSR_DIR` 直接钉死（多个目录用 `;` 分隔）。
>
> 本仓库**不随包分发**争渡的 `ZDSRAPI_x64.dll` / `ZDSRAPI.dll`（版权归争渡所有）；
> 如果你把这两个文件放到游戏根目录，模组也会用。
>
> 判断争渡能不能用，只看 `GetSpeakState()` ∈ {3, 4} ——
> `InitTTS` 返回 0 只表示版本对得上，`Speak()` 返回 0 也不表示成功；
> 拿 `Speak()` 当判据会得到「配置选了争渡、日志一片绿、耳朵一片安静」。
>
> 争渡的 API 权限只随**商业版 / 青春版**提供；公益档下 `GetSpeakState()`
> 会如实返回不可用，模组会继续往下试 SAPI，而不是假装成功。
>
> **争渡这一档在本作里还没有实机验证**：接口判据在本机核对过（`GetSpeakState()`
> 返回 4），但「游戏里听到的是不是争渡自己的声音」需要人工确认。

## 已知问题 / 注意事项

- 标题菜单出现时，引擎会把整屏文字念一遍（"开始游戏: 读取游戏: 设置: …"），
  之后用方向键逐项浏览才是逐项的。这是 Ren'Py 自语音的整屏朗读行为，不是补丁加的
- `say` 界面上的日期装饰「2023年」会先单独念一次（同样是引擎读屏根的整屏朗读）；
  补丁已经把台词本体修正为只念台词，但这一条整屏朗读不在补丁接管范围内
- 设置里的滑条具体数值变化、读档界面的纯数字跳页输入框，尚未逐项实机核对
- 未覆盖：CG / 手书演出的画面口述、视频、真结局后的商店广告菜单
  （那个菜单不朗读，键盘也绕开它，避免误触 `OpenURL`）
- 中文语音需要系统里有中文嗓音（SAPI 档）；NVDA 档需要 NVDA 正在运行；
  争渡档需要争渡商业版 / 青春版的 API 权限
- **只在无头测试和文本层验证过**：自动化能断言"念了什么、什么时候念"，
  不能证明"真的从音箱里出来了"；NVDA / 争渡 / SAPI 三条档位的真机发声都需要人工确认
- 本作没有限时选择、没有小游戏；选项数字键在本作里不涉及倒计时抢占

## 构建

Ren'Py 覆盖层补丁**没有编译步骤** —— `.rpy` 是文本，复制进游戏即被加载。
打包发布：

```powershell
pwsh -File tools\make-release.ps1
```

会生成 `release\MeiNiangLoveForAccessibility-<版本>.zip`。
需要 PowerShell 5.1+；`tools\*.ps1` 全部保存为 **UTF-8 带 BOM**。

> `.ps1` 必须带 BOM —— Windows PowerShell 5.1 读无 BOM 的脚本会按 GBK 解码，
> 中文注释变乱码并直接语法错误。这是本项目踩过的坑之一。

### 模组做了什么

| 功能 | 挂载点 |
|---|---|
| 台词朗读 | 接管 `config.tts_function`（引擎自语音 `renpy.display.tts` 的公开出口） |
| 台词只念本体 | `renpy.display.behavior.SayBehavior._tts_all`（改读台词 `text_tuple`，不念 say 界面装饰） |
| 图片按钮文字 | `renpy.display.behavior.Button._tts_all`（补上 `ImageButton` 画出来的 `foreground` 文字） |
| 界面焦点朗读补偿 | `renpy.display.tts.displayable`（引擎焦点事件 `renpy.display.focus` 的唯一出口） |
| 关掉配音守卫 | `config.tts_voice_channels = []`（否则有配音的台词被引擎整体吞掉） |
| 数字键选选项 | `config.keymap` + `renpy.Keymap`（与引擎自己的 `_default_keymap` 同一种绑定方式），动作调 `renpy.run(item.action)` |
| Backspace 重读 / 切后端 | 同上，`config.keymap["mne_repeat_line"]` / `["mne_cycle_backend"]` |
| 默认开启 | 首次启动写 `preferences.self_voicing = True`，即玩家按一次 `V` 的等价操作 |

**判定有无配音的方式**：复刻游戏自己的 `config.auto_voice` 规则
（`voice/{id}.flac` + 当前 `translate_identifier`），再用 `renpy.loadable(..., directory="audio")`
确认文件真的在 —— 不看 `voice` 声道是否正在播放（会被上一句的 sustain 干扰）。

### 几条踩过的坑（改之前请先读）

- **`renpy/common/00keymap.rpy` 会 `import os` 再 `del os`**：store 里的 `os` 在
  init -1600 之后就不存在了。补丁必须 `import os as _mne_os`，否则运行期
  `NameError` 会让每一句朗读都静默失败
- **`config.underlay` 是在 `init -1100` 被整体赋值的**：补丁的 `renpy.Keymap`
  必须 append 在 `init -1000`（或更晚），写在 `init -1400` 会被引擎整体赋值冲掉
- **`config.tts_substitutions` 是 `[(pattern, 替换)]` 列表，且只在启动早期
  被 `renpy.display.tts.init()` 编译一次**：init -1800 再改它不会生效。
  补丁自己编译正则（`_mne_apply_subs`）
- **测试框架里 `$` 单行 Python 会挂死**：必须用 `python:` 块
- **`keysym` 之后接 `pause` 会 5 秒超时**：引擎处于 `trans_pause/ongoing_transition`
  时测试节点时钟不前进，主菜单/界面里要先用 `advance until screen "main_menu"`
  等到界面出现，再发按键
- **无头（SDL dummy + `sw` 渲染）下大 CG + `dissolve` 会崩引擎**（0xC0000005，
  不装补丁也崩）：自动化用例要避开带大 CG 的过场，换一条只有立绘的分支
- **旧 `.rpyc` 不删会盖住新 `.rpy`**：改完代码没反应时先删 `game\a11y_platform\*.rpyc`
- **别用 PowerShell 的文本 cmdlet 改源码**：`Get-Content -Raw` 在 Windows
  PowerShell 5.1 下按 ANSI 代码页读取无 BOM 的 UTF-8，中文会变乱码

## 如何复现分析

分析过程用游戏自带的 Ren'Py 8.5.2 运行时（`<游戏目录>\lib\py3-windows-x86_64\python.exe`）
加载 `.rpyc`（压缩 pickle）与 `.rpa`（Ren'Py 归档），把脚本还原成可读的 AST/伪源码；
界面结构来自 `screens.rpa` 里的 `screens*.rpyc`。生成的 `extracted/`、`decompiled/`
均为游戏版权内容，**已被 `.gitignore` 排除，请勿提交或分发**。

补丁本身需要的引擎证据（自语音出口、焦点事件、键位机制、测试框架）全部来
游戏自带的 `renpy/` 源码 —— 补丁只调用这些公开机制，不改引擎文件。
